# Premium Auto Parts E-Commerce Platform

A modern, production-ready automotive parts e-commerce platform built with
Next.js, React, TypeScript, Tailwind CSS, Supabase, and Stripe.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- ShadCN UI
- Framer Motion
- Supabase


## Key Features

- Product catalog and advanced search
- Vehicle compatibility
- Product filters and comparison
- Shopping cart and checkout
- Wishlist
- Reviews and ratings
- WhatsApp enquiry
- Order management
- Inventory management
- Coupon and discount system
- Admin dashboard
- Blog and SEO system
- Responsive mobile-first design
- Product and review structured data
- Dynamic sitemap and metadata
